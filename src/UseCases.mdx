# Use cases

The catalog answers _"which Card?"_. This page answers _"how do I build the thing I was
asked for?"_ — intent first, then the parts, then a composition to copy.

Each family's **Overview** compares its members; the **(Demo)** entries are Storybook-only
compositions, not exports.

**Track work through stages · triage a queue · plan a programme**

## When nothing here fits

Read the family Overview closest to your intent before building: it states the boundary
between its members and usually names the component you actually wanted. If a real gap
remains, [CONTRIBUTING → Developing Components From a Consuming
Application](https://github.com/mieweb/ui/blob/main/CONTRIBUTING.md#developing-components-from-a-consuming-application)
is the path upstream, and [component-policy](https://github.com/mieweb/ui/blob/main/lessons/component-policy.md)
is how to build it locally so it can get there.
