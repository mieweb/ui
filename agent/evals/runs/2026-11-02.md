## Findings and fixes filed

1. **SEL-12 FAIL — design agent can't answer headless-wiring questions and
   didn't route them.** The knowledge lives in the tailwind4 skill ("Wiring
   headless modules", Install agent's source), but the orchestrator's routing
   table had no wiring row. _Fix:_ added a routing row (wiring headless
   modules → MIE UI Install Agent) to `mieweb-ui-design.agent.md`.
2. **STY-13 FAIL — corpus gap caused a wrong diagnosis.** Nothing in the
   corpus covered the brand CSS's unlayered `*` transition shorthand beating
   layered `transition-*` utilities (open #460/#682); the agent
   mis-attributed the symptom to the brand-without-base pitfall. _Fix:_
   troubleshooting rows added to the tailwind4 skill and
   `lessons/tailwind4-integration.md` (fix = layer the transition rule, not
   scope it — it already lists only color properties).
3. **INS-14 PARTIAL — honest corpus gap on installing from git source**
   (#489). _Fix:_ install note added to the tailwind4 skill (published npm
   package only; source tree is a pnpm workspace with `link:` deps).
4. **A11Y-17 PARTIAL — corpus silent on exit-animation semantics**, and the
   eval's own Expect overstated the motion layer (`AnimatedPresence` does
   NOT yet hide exiting children — open #474). _Fix:_ exit-animation note
   added to the a11y-checklist skill; eval entry corrected to cite #474 as
   open.
5. **STY-14 PARTIAL — preset drift (#628) unknowable from corpus.** The
   generic safelist/content diagnosis is correct behavior; the drift itself
   is an open library bug, not a corpus gap. _Fix:_ eval Expect rewritten to
   match the corpus-known-good diagnosis path, citing #628 as open.
6. **SEL-16 eval defect — ambiguous Ask.** "Sometimes… sometimes" read as one
   component needing both behaviors; the agent correctly mapped all three
   badges but declared a gap. _Fix:_ Ask rephrased to three distinct
   placements.

No findings for i18n or migration — both specialists answered their samples
fully from the corpus, including the root-barrel icon shadows (MIG-3) and the
behavior-change judgment call (MIG-18).
